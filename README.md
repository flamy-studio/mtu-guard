# MTU Guard

Помощник для AmneziaVPN на Windows.

MTU Guard — простое исправление для AmneziaVPN на Windows, которое помогает решить распространённую проблему с открытием сайтов и работой приложений. Программа автоматически применяет нужную настройку подключения Withen Network и поддерживает её после переподключения VPN, чтобы вам не приходилось делать это вручную.

Проект разработан и издаётся [Flamy Studio](https://flamy.studio) по заказу [Withen Network](https://withen.pro).

[Выпуски и загрузки](https://github.com/flamy-studio/mtu-guard/releases) · [Ручной режим](docs/MANUAL_MTU.md) · [Сообщить о проблеме](https://github.com/flamy-studio/mtu-guard/issues)

## Что умеет MTU Guard

- Проверяет нужный параметр подключения AmneziaVPN и исправляет его при необходимости.
- Может работать в фоне и автоматически проверять подключение после его изменения.
- Позволяет выполнить разовую проверку или исправление без установки фонового помощника.
- Показывает результат проверки и объясняет, когда нужно подключить VPN или обратиться за помощью.

Для работы нужна установленная AmneziaVPN. Дополнительные программы устанавливать не требуется.

| **Ручной режим 0.1** | **Базовое исправление — PASS по отчёту испытателя Windows 10.** Расширенные сценарии продолжают проверяться. |

## Какой вариант выбрать

| Вариант | Когда подходит | Что запускать |
|---|---|---|
| Автоматический | Хотите настроить один раз, чтобы помощник работал в фоне | `install.cmd`, затем `status.cmd` для проверки |
| Ручной | Хотите проверить или исправить подключение один раз | `manual-mtu.cmd`; только проверка — `manual-check.cmd` |

Полный пакет включает оба режима. Для работы только вручную есть отдельный компактный пакет. Если в разделе «Выпуски» ещё нет готового пакета, используйте пакет, который вам передали для проверки. Архив исходного кода не подходит для установки автоматического варианта.

## Как начать

### Автоматический режим

1. Распакуйте готовый пакет целиком в обычную папку.
2. Откройте `install.cmd` двойным щелчком и подтвердите запрос администратора Windows.
3. Дождитесь сообщения `Installation complete`.
4. Подключите AmneziaVPN и откройте `status.cmd`.

После установки помощник запускается вместе с Windows. Подключать VPN и пользоваться им можно как обычно.

### Ручной режим

Распакуйте ручной пакет, подключите AmneziaVPN и откройте `manual-mtu.cmd`. Выберите **1** для проверки или **2**, чтобы установить MTU 1280. Windows запросит права администратора, только если значение действительно нужно изменить.

Ручное исправление действует до тех пор, пока AmneziaVPN или Windows не изменят настройку снова. После переподключения может потребоваться повторная проверка. [Подробная инструкция ручного режима](docs/MANUAL_MTU.md).

## Что означают сообщения

- **PASS** — нужное значение MTU установлено.
- **WAITING** — подходящее подключение пока не найдено. Подключите AmneziaVPN и повторите проверку.
- **WARN** — значение отличается от рекомендуемого или не прошла дополнительная проверка. Прочитайте сообщение рядом.
- **FAIL** — проверку или исправление выполнить не удалось. Если указано `AMBIGUOUS`, найдено несколько подходящих подключений и программа ничего не меняла.

PASS подтверждает настройку MTU. Если сайт или приложение по-прежнему не открывается, причина может быть другой — сохраните сообщение программы и обратитесь за помощью.

## Как удалить

В автоматическом варианте откройте `uninstall.cmd` и подтвердите запрос Windows. Ручной вариант устанавливать и удалять не нужно: достаточно закрыть его окно.

## Если нужна помощь

Сообщите о проблеме через [репозиторий проекта](https://github.com/flamy-studio/mtu-guard/issues) или свой канал поддержки [Withen Network](https://withen.pro). Укажите версию Windows и AmneziaVPN, выбранный режим и сообщение программы. Пароли, ключи и конфигурацию VPN отправлять не нужно.

Если Windows блокирует запуск, не отключайте защиту ради утилиты — сообщите об этом вместе с текстом предупреждения.
