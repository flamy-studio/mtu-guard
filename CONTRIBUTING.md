# Contributing

Проект принимает исправления, тесты и уточнения совместимости Windows 10/11.

MTU Guard разработан и издаётся [Flamy Studio](https://flamy.studio) по заказу [Withen Network](https://withen.pro).
Сборка, команды и устройство проекта: [DEVELOPMENT](docs/DEVELOPMENT.md).
Основной репозиторий: https://git.flamy.studio/prod/Withen_MTU_Guard.

- Для каждого изменения нужен краткий issue/PR с описанием проблемы и воспроизведением.
- Проверки Windows: `build.ps1` (форматирование без перезаписи, тесты, Clippy, release EXE/PDB и проверка ресурсов). Cargo-команды используют `--locked`; изменения `Cargo.lock` проверяются вместе с зависимостями.
- Любой новый вызов Win32 должен иметь ссылку на Microsoft Learn, локализованный блок `unsafe` и аргументацию безопасности.
- Не расширять полномочия службы, не добавлять сетевую телеметрию или автоматическую загрузку бинарников без отдельного дизайн-ревью.
- Не публиковать VPN-конфигурации, пароли, закрытые ключи и пользовательские IP.
- Изменения установки/обновления требуют подтверждения Windows 10 + Windows 11 E2E.
- Новые contributors соглашаются на Apache License 2.0 и подтверждают право на отправляемый код.
- Не использовать UPX, обфускаторы или удаление release-символов. Не запускать оболочки из runtime для настройки MTU; применять штатный IP Helper API.
- Сохранять статическую CRT из `.cargo/config.toml`. Добавление DLL допустимо только после отдельного обоснования; PE-проверка обычных и отложенных импортов обязательна.
- Обновлять `SHA256SUMS_SOURCE.txt` через `scripts/update-source-checksums.ps1`, проверять с `-Verify`. Артефакты EXE/PDB/ZIP передавать через релизы, а не коммитить в исходники.
