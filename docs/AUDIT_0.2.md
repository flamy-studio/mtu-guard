Исторический отчёт версии 0.2. Результаты этой сборки: [BUILD_REVIEW_0.2](BUILD_REVIEW_0.2.md). Изменения выбора адаптера в 0.3 описаны отдельно: [NET-002](NET-002.md).

Основание: письменный аудит `WITHEN_MTU_Guard_0.1_code_audit_2026-11-21.md` и дополнительный текст пользователя. Проверенный там EXE 0.1 имел SHA-256 `51b92cad7fa5126e769139f8891bbd8d9165adff8da9d9620e390ba1fa364c75`. Рекомендации из документов сопоставлены с текущими исходниками и проверены; результаты поля не подменяются анализом кода.

## Граница подтверждения

Пользователь сообщил, что сейчас доступен только текущий ПК, и передаст готовый пакет тестировщикам. Поэтому **чистые Windows 10/11, реальное переключение split tunneling, исправление наблюдаемого MTU 1376, перезагрузка и час измерений не объявляются выполненными**. Это явно оставшиеся условия приёмки, а не отсутствующие скрипты.

На текущем ПК реальный SCM-тест окончательного установщика завершился PASS; тестовые служба и файлы удалены. Две остановки заняли 0,008 / 0,253 с. Повторная установка проверена для 0.2 поверх 0.2; миграция ранее установленной 0.1 отдельно не заявляется.
