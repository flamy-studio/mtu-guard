# MTU Guard 0.3.0 — сводное решение по полевой совместимости

**Дата решения:** 23.11.2026\
**Репозиторий:** https://github.com/flamy-studio/mtu-guard\
**Релиз:** https://github.com/flamy-studio/mtu-guard/releases/tag/v0.3.0\
**Уровень подтверждения:** реальные пользовательские испытания, не сертификация Windows или всех возможных конфигураций.

## Совместимость

| Платформа / компонент | Статус | Фактический объём проверки |
|---|---|---|
| Windows 11 x64 — автоматическая служба 0.3.0 | **VERIFIED (field-tested)** | Два независимых ПК; установка, коррекция 1376 → 1280, работа после переподключения и переключения Split Tunneling, повторный запуск клиента, reboot и HTTPS через WRE |
| Windows 10 x64 — автоматическая служба 0.3.0 | **VERIFIED (field-tested)** | Windows 10 build 19045, без средств сборки: установка, служба RUNNING, исправление по логу, WAITING, возврат интерфейса, HTTPS, непрерывный процесс ~3:59, низкая нагрузка в контрольной точке |
| Windows 10 — ручной инструмент 0.1, пункт 2 | **BASIC FIELD PASS (reported)** | Испытатель сообщил об успешном ручном исправлении MTU через `manual-mtu.cmd` → 2; отдельного протокола запуска нет |
| Windows 11 — ручной инструмент 0.1 | **PARTIAL / developer-tested** | По документации исходников: чтение MTU, HTTPS, модельные проверки; отдельный полный пользовательский E2E на Windows 11 не предоставлен |
| Windows ARM64 и x86 | **NOT COVERED** | Пакет предназначен для Windows x64 |

## Решение о релизе

- Основная служба **MTU Guard 0.3.0** допускается к распространению для **Windows 10 x64 и Windows 11 x64** с пометкой **Verified / field-tested**.
- Для Windows 10 слово `Verified` обозначает подтверждение на реальном **Windows 10 build 19045**; не следует выдавать его за проверку всех выпусков Windows 10 и системных политик.
- Ручной инструмент полезен и его стандартный сценарий 1280 получил положительный полевой результат на Windows 10. Расширенная матрица ручных сценариев и граничные проверки не закрыты.
- Изменять тег `v0.3.0`, перезаписывать опубликованный ZIP или пересобирать программу ради нового статуса совместимости не требуется. Обновляются **README, документы приёмки и при необходимости текст GitHub Release**.

## Доказательства и ограничения

**Windows 11:** [подробный отчёт](FIELD_ACCEPTANCE_WINDOWS11_2026-11-22.md).\
**Windows 10:** [подробный отчёт](FIELD_ACCEPTANCE_WINDOWS10_2026-11-23.md).\

Открыты для отдельного стенда: числовые имена адаптеров на реальной машине; одновременные два пригодных интерфейса; отрицательные сценарии UAC; произвольное MTU; гарантированная работа в организациях с ограничивающими политиками; проверка установки на строго чистом образе Windows; отдельный сквозной тест удаления и повторной установки у внешнего участника.

**Важно:** правильный MTU = 1280 подтверждён для испытанного профиля WITHEN. Это не универсальное значение для любых VPN.
