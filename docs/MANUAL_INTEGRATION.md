## Что исправлено при интеграции

- `Get-NetIPInterface` возвращает CIM-свойство `NlMtu`. Исходный скрипт обращался к несуществующему `NlMtuBytes` и компенсировал это разбором netsh. Корректное свойство проверено на текущей Windows и по контракту MSFT_NetIPInterface; netsh- и curl-процессы из ручного инструмента убраны.
- Ошибки чтения IPv4 больше не подавляются. Один ActiveStore-снимок используется для всех потенциальных кандидатов; ошибка прекращает выбор. Неизвестный MTU не скрывает кандидата и запрещает слепую запись.
- До/после записи сравниваются GUID, индекс, точное имя и compartment. Идентичность цели сохраняется при UAC; её смена запрещает запись. Если другой процесс уже исправил MTU, запись пропускается.
- Setter ограничен IPv4, ActiveStore и конкретными alias/index/compartment; передаётся только изменение MTU. Произвольные сетевые настройки не добавлены.
- HTTPS отделён от результата MTU, использует .NET Windows без curl. Меню предлагает его отдельно. Выход из меню не печатает ложный PASS проверки; окно не требует двух подтверждений Enter после UAC.
- Вместо теста наличия строк добавлен 31 поведенческий PowerShell-тест, включая ошибки API, неоднозначность, гонки, UAC, параметры setter и провал верификации. В тестах запись/повышение/ожидание подменены.
- `build.ps1` запускает новые тесты; упаковка будущих полных выпусков включает оба скрипта и CMD. `package-manual.ps1` создаёт отдельный автономный ручной кандидат с LICENSE, NOTICE и всеми SHA-256. Исходный манифест теперь включает каталог `tools` и вложенные документы аудита.

## Фактические проверки

Полный `build.ps1`: 34 Rust-теста, rustfmt, Clippy с `-D warnings`, release, PE/ресурсы/PDB и все PowerShell-наборы PASS. Для ручного инструмента дополнительно проверено ASCII-сопоставление имён при турецкой локали Windows. Исходный аудит сохранён побайтно; его SHA-256 совпадает с входным файлом.

Windows PowerShell 5.1: 31 поведенческий тест PASS. На текущем ПК `-Mode Check` показал реальный `AmneziaVPN` / MTU 1280; HTTPS вернул 200. `-Mode Fix -Mtu 1280` при уже правильном значении завершился без записи и UAC. Во время этого smoke-теста setter и запуск UAC дополнительно блокировались: попыток не было.

Служба и сетевые параметры текущего ПК ради приёмки ручного инструмента не изменялись. Новая установка SCM не нужна: Rust/установщик не менялись. Реальная запись через NetTCPIP, Windows 10 и UAC с записью — NOT RUN. Подробная инструкция: [MANUAL_MTU](MANUAL_MTU.md); сценарии T35–T39 — [TESTING](TESTING.md).
