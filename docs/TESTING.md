# Приёмка MTU Guard 0.3 — Windows 10/11

На текущей Windows 11 26H2 (26300.9974) выполнены `build.ps1`, 34 Rust-теста, Clippy, PE/installer/status-parser-тесты, read-only диагностика и реальный SCM-тест 0.3 после подтверждения UAC. Проверены установка, ACL, stop/start, повторная установка и удаление. Эта машина содержит средства разработки; она не заменяет чистые Windows 10/11. Пользователь передаёт готовый пакет внешним тестировщикам.

SCM-результаты в матрице относятся к первоначальному файлу 0.3. Текущая пересборка с обновлённым брендингом и документацией прошла сборочные/модельные и read-only проверки; её EXE отдельно в SCM не переустанавливался. См. [актуальный отчёт](BUILD_REVIEW.md).

## Сбор результатов

Инструкция и готовые команды: [FIELD_TESTS.md](FIELD_TESTS.md). В пакет включены `tests/clean-runtime.ps1`, `tests/windows-integration.ps1` и `scripts/collect-evidence.ps1`.

Для реальной смены MTU/переключения VPN нужен добровольный тест на подходящем ПК: не следует обрывать рабочий туннель ради автоматической проверки. Фиксировать точные версии Windows и AmneziaVPN, времена переходов, LUID/ifIndex и результат HTTPS. Скрипты не собирают ключи, профили или адреса; перед отправкой дополнительно просмотреть файлы результатов.

## Готовность

Сборка, модельные проверки и SCM 0.3 на текущем ПК прошли; публичный выпуск остаётся кандидатом до приёмки чистых Windows 10/11, числовых имён, T23/T28, пользовательских приложений и безопасности распространения. Подпись Authenticode не добавлена. Не отмечать NOT RUN как PASS по одним исходникам.
