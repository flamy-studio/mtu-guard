# Приёмка MTU Guard 0.3 — Windows 10/11

**Пользовательская приёмка 22.11.2026:** автоматический режим 0.3.0 — **Windows 11 x64 VERIFIED / PASS** на двух реальных ПК. **Windows 10 x64 — EXPERIMENTAL**, **ручной режим — TEST CANDIDATE**. Подробные действия A01–A10/B01–B09, оговорки атрибуции и остающиеся сценарии: [полный отчёт](FIELD_ACCEPTANCE_WINDOWS11_2026-11-22.md).

Сборочные проверки, 34 Rust-теста, Clippy, PE/installer/status-parser и 31 тест ручного инструмента ранее прошли на Windows 11 26H2 разработчика. Локальная SCM-проверка и пользовательская приёмка — разные источники подтверждения. Ни один из этих ПК автоматически не признаётся чистой Windows без средств разработки.

## Сбор результатов

Инструкция и готовые команды: [FIELD_TESTS.md](FIELD_TESTS.md). В пакет включены `tests/clean-runtime.ps1`, `tests/windows-integration.ps1` и `scripts/collect-evidence.ps1`.

Для реальной смены MTU/переключения VPN нужен добровольный тест на подходящем ПК: не следует обрывать рабочий туннель ради автоматической проверки. Фиксировать точные версии Windows и AmneziaVPN, времена переходов, LUID/ifIndex и результат HTTPS. Скрипты не собирают ключи, профили или адреса; перед отправкой дополнительно просмотреть файлы результатов.

## Готовность

Основной сценарий автоматического MTU Guard 0.3.0 на Windows 11 x64 — VERIFIED / PASS по двум пользовательским установкам. Windows 10 остаётся EXPERIMENTAL, ручной режим — TEST CANDIDATE. Чистые ОС, числовые имена/неоднозначность, холодное включение питания, час нагрузки и подпись не считаются закрытыми. Версия не повышается; текущие бинарники и ZIP сохраняются. Не переносить результаты за пределы описанных условий.
