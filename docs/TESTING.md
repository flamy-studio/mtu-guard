# Приёмка MTU Guard 0.3 — Windows 10/11

**Текущий итог 23.11.2026:** основная служба 0.3.0 — **Windows 10 x64 VERIFIED / PASS** (build 19045) и **Windows 11 x64 VERIFIED / PASS** (два ПК). Длительная работа службы Windows 10 — **PASS**. Ручной инструмент 0.1, пункт 2 на Windows 10 — **PASS по сообщению испытателя**, расширенная матрица проверена частично.

[Сводное решение](FIELD_ACCEPTANCE_SUMMARY_2026-11-23.md), [Windows 10 W10-01…W10-16/W10-M01…M05](FIELD_ACCEPTANCE_WINDOWS10_2026-11-23.md), [Windows 11 A01…A10/B01…B09](FIELD_ACCEPTANCE_WINDOWS11_2026-11-22.md). Пользовательская приёмка, локальные SCM-проверки, 34 Rust-теста и 31 модельный тест ручного инструмента — разные источники доказательств. Пользовательская система без средств сборки не считается автоматически строго чистым образом без VC++ Runtime.

## Сбор результатов

Инструкция и готовые команды: [FIELD_TESTS.md](FIELD_TESTS.md). В пакет включены `tests/clean-runtime.ps1`, `tests/windows-integration.ps1` и `scripts/collect-evidence.ps1`.

Фиксировать точные версии Windows и AmneziaVPN, времена переходов, LUID/ifIndex и результат HTTPS. Скрипты не собирают ключи, профили или адреса; перед отправкой дополнительно просмотреть файлы результатов.

## Готовность

Основной автоматический MTU Guard 0.3.0 — VERIFIED / PASS на Windows 10 x64 build 19045 и Windows 11 x64 (два ПК). Длительная работа Windows 10 и базовый ручной сценарий Windows 10 приняты: соответственно PASS evidence и PASS reported. Неполная расширенная матрица не отменяет эти результаты. Числовые имена, несколько активных интерфейсов, отрицательные UAC, нестандартный MTU, строгие чистые образы и временной профиль ресурсов сохраняют собственные статусы. Версия 0.3.0 и опубликованные файлы не меняются.
