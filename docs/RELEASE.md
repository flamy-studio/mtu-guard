# Релизный процесс MTU Guard 0.3

Разработчик и издатель: [Flamy Studio](https://flamy.studio). Заказчик: [Withen Network](https://withen.pro). Репозиторий — GitHub: https://github.com/flamy-studio/mtu-guard. GitHub workflow отсутствует; автоматическая сборка не настроена.

1. Синхронизировать пользовательскую версию `VERSION` (`0.3`), `Cargo.toml` / `Cargo.lock` (`0.3.0`) и `app.manifest` (`0.3.0.0`). Проверить CHANGELOG. Ресурсы EXE берут версию из Cargo.
2. Сохранять `.cargo/config.toml` со статической CRT. Не переопределять `RUSTFLAGS` так, чтобы исчез `+crt-static`. Проверить изменения lockfile и зафиксировать исходники для выпуска.
3. На Windows x64 выполнить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1`. Получить успешные PE/installer/status-parser-тесты, rustfmt, Rust-тесты, Clippy, release, проверку ресурсов и DLL. EXE/PDB и `SHA256SUMS.txt` создаются в корне, артефакты исключены из Git.
4. Обновить исходные контрольные суммы через `scripts/update-source-checksums.ps1` и проверить с `-Verify`. Сохранить версии Rust/MSVC/SDK и результаты из [BUILD_REVIEW](BUILD_REVIEW.md); не выдавать builder за чистую Windows.
5. При наличии доверенного сертификата подписать EXE Authenticode на защищённом этапе. Секреты не хранить в исходниках. После подписи повторить проверку ресурсов/импортов и только затем рассчитывать финальные SHA-256.
6. Выполнить `scripts/package.ps1`. Получить `dist/MTU-Guard-0.3.0-win-x64.zip` и `dist/RELEASE_SHA256SUMS.txt`. ZIP содержит EXE/PDB, установщик, диагностику, тесты, VERSION, документацию, LICENSE/NOTICE и `SHA256SUMS.txt` для всех вложенных файлов. Обычное ZIP-сжатие не меняет EXE; UPX запрещён.
7. Перед передачей проверить SHA-256 ZIP, CRC и все записи внутреннего манифеста после распаковки. Для тестировщика использовать [FIELD_TESTS](FIELD_TESTS.md).
8. Пройти [TESTING](TESTING.md), включая чистые Windows 10/11, числовые имена и неоднозначность (T29–T34), split tunneling, восстановление после холодного старта и час наблюдений. Не переносить результаты одного ПК на всю матрицу.
9. Тег, публичный релиз GitHub, EXE/PDB/ZIP и контрольные суммы публикует оператор после приёмки. Бинарные файлы не коммитить в Git.

## Текущий результат

После 0.3 в исходники добавлен Unreleased ручной инструмент 0.1. Для отдельного ZIP без EXE/SCM выполнить `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\scripts\package-manual.ps1`. Скрипт сначала запускает 31 поведенческий тест и создаёт `dist/MTU-Guard-manual-0.1-win-x64-candidate.zip` с отдельной суммой `.zip.sha256`. Внутри — CMD, оба PS-скрипта, инструкция, LICENSE/NOTICE и SHA-256 всех файлов. Существующий ручной кандидат перезаписывается только с `-Overwrite`. Отдельная ручная упаковка не меняет полный ZIP. Оба актуальных кандидата повторно собраны 22.11.2026; прежние архивы удалены из dist, текущие суммы описаны в BUILD_REVIEW.md.

Будущая полная упаковка включает оба ручных скрипта, CMD и вложенный исходный аудит. Перед новым полным выпуском назначить новую версию и пройти соответствующие T35–T39; не перезаписывать опубликованный или переданный для тестов ZIP 0.3.

Полный упаковщик также отказывается заменять существующий архив без явного `-Overwrite`; этот ключ предназначен для осознанной замены локального кандидата.

0.3 собран на текущей Windows 11; 34 Rust-теста, Clippy, ресурсы, статическая CRT и проверки PowerShell прошли. Диагностика текущего адаптера и JSONL работают. Реальный SCM-тест 0.3 прошёл после подтверждения UAC: установка, ACL, два stop/start, повторная установка и удаление; остановки 0,008 / 0,257 с. По последующему [полевому отчёту 22.11.2026](FIELD_ACCEPTANCE_WINDOWS11_2026-11-22.md) автоматический режим 0.3.0 — Windows 11 x64 VERIFIED / PASS на двух ПК: коррекция MTU, переподключения, раздельное туннелирование, перезапуск клиента и reboot. Windows 10 — EXPERIMENTAL, ручной режим — TEST CANDIDATE. Чистые ОС, числовые имена, холодное включение питания, час нагрузки и Authenticode-подпись остаются отдельными условиями; версия 0.3.0 из-за отчёта не повышается. Старый статус Code Integrity 4551 относится к предыдущим попыткам 0.1 и не является текущей блокировкой.
