# Проверка сборки MTU Guard 0.3

Дата: 22.11.2026. Разработчик и издатель: [Flamy Studio](https://flamy.studio). Заказчик: [Withen Network](https://withen.pro). Apache-2.0.

## Результат

**Кандидат 0.3.0 собран на текущей Windows 11.** Реализован [NET-002](NET-002.md): числовые имена от 1, единственный подходящий Up+IPv4-интерфейс без hardware, повторная проверка выбора/LUID перед записью и фактический alias в диагностике. Статическая CRT сохранена; VC++ Redistributable и сторонние DLL для запуска EXE не требуются.

Среда: Windows 11 26H2 (26300.9974), Rust/Cargo 1.100.0, MSVC Build Tools 2022 (14.44.35207), Windows SDK 10.0.26100.0. Текущий ПК содержит dev tools и восемь регистраций VC++ Runtime, поэтому не считается чистой Windows. Полевые сценарии не подменяются модельными тестами.

## SCM и границы подтверждения

Реальный тест 0.3 выполнен 22.11.2026 в 00:56:37 CET. Проверены кавычки ImagePath в Program Files, Auto/LocalSystem, защищённые ACL, два stop/start, повторная установка 0.3 поверх 0.3 и повторное удаление. До теста существующей установки/логов не было; после теста служба и её каталоги удалены.

Остановки: **0.008 / 0.257 с**. Короткая выборка простоя: **5.006 с**, delta CPU **0 с**, working set **6246400 байт**, private bytes **1126400 байт**. Это не часовой тест нагрузки и не подтверждение буквального Zero CPU.

Локальные протоколы: `target/review/scm-0.3.json`, `scm-0.3-transcript.txt`, `scm-0.3.json.guard.log`. Транскрипт с персональными заголовками в ZIP не включён. Миграция установленной 0.1/0.2 отдельно не проверялась.

Реальный адаптер текущего ПК называется `AmneziaVPN`, описание `WireGuard Tunnel`, тип 53, Up, hardware=false; MTU уже 1280. Рабочий VPN не переключался, адаптеры не переименовывались, MTU 1376 намеренно не задавался. Поэтому **реальная запись 1376 → 1280, числовой адаптер, несколько настоящих подходящих интерфейсов, split tunneling, холодный старт, чистые Windows 10/11 и час нагрузки — NOT RUN**. Эти сценарии передаются внешним тестировщикам. Между последним чтением и Set остаётся неатомарное окно; нулевая задержка коррекции не гарантируется.

Локальные read-only протоколы: `target/review/runtime-0.3.json`, `observations-0.3.jsonl`; журнал сборки — `build-0.3.log`. Ключи, профили и адреса не собирались.
