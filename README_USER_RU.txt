MTU Guard 0.3 — помощник для AmneziaVPN на Windows

Разработчик и издатель: Flamy Studio — https://flamy.studio
Заказчик: Withen Network — https://withen.pro

MTU Guard помогает исправить проблему AmneziaVPN с открытием сайтов
и работой приложений. Помощник автоматически поддерживает нужную настройку
подключения Withen Network, в том числе после переподключения VPN.
Для работы нужны Windows 10/11 (64-разрядная версия) и AmneziaVPN.

Автоматический вариант работает в фоне:
1) Распакуйте готовый пакет целиком.
2) Откройте install.cmd и подтвердите запрос администратора Windows.
3) Дождитесь Installation complete.
4) Подключите AmneziaVPN и откройте status.cmd.

PASS — нужное значение установлено.
WAITING — подключите AmneziaVPN и повторите проверку.
WARN — прочитайте сообщение о том, что требует внимания.
FAIL — проверка или исправление не удались; сохраните сообщение для поддержки.
AMBIGUOUS — найдено несколько подходящих подключений, изменения не выполнялись.

После установки помощник запускается вместе с Windows.
Для удаления откройте uninstall.cmd и подтвердите запрос Windows.
Дополнительные программы устанавливать не требуется.

Ручной режим есть в полном и в отдельном компактном пакете:
manual-check.cmd — только проверить, manual-mtu.cmd — проверить и исправить.
Подробности: docs\MANUAL_MTU.md.

Проект пока проходит тестирование. Используйте готовый пакет от издателя:
архив исходного кода не подходит для установки автоматического варианта.
Если Windows блокирует запуск, не отключайте защиту — сообщите в поддержку.
PASS MTU не гарантирует доступность всех сайтов и приложений.
