MTU Guard — ручной инструмент 0.1
Базовый пункт 2: PASS по отчёту испытателя Windows 10.
Расширенные сценарии проверены частично; отдельного лога ручного запуска нет.

Разработчик и издатель: Flamy Studio — https://flamy.studio
Заказчик: Withen Network — https://withen.pro

Распакуйте весь архив в обычную папку и подключите AmneziaVPN.
manual-check.cmd — проверить подключение без прав администратора.
manual-mtu.cmd — меню: 1 — проверить, 2 — исправить на 1280, 4 — выйти.
Пункт 3 с другим значением MTU предназначен для согласованных тестов.
Windows запросит права администратора, только если нужна запись изменения.

PASS — нужное значение MTU установлено.
WAITING — подключите AmneziaVPN и повторите проверку.
AMBIGUOUS — найдено несколько подходящих подключений, изменения запрещены.
При FAIL сохраните сообщение и передайте его в поддержку.

Это разовое исправление. После переподключения VPN или перезагрузки
проверку может потребоваться повторить. Фоновый помощник не устанавливается.
Если служба MTU Guard уже работает, она будет возвращать MTU к 1280.

Меню отдельно предлагает проверить доступ к сайту Cloudflare.
Успешная проверка MTU не гарантирует работу всех сайтов и приложений.
Не отключайте защиту Windows ради запуска утилиты.

Подробная инструкция: docs\MANUAL_MTU.md.
